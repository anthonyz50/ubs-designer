# Design Tokens

All design decisions in the UBS Design System are captured as typed tokens. These tokens are the single source of truth for spacing, breakpoints, z-index, layout, transitions, and more.

## Breakpoints

The UBS responsive system uses four breakpoints aligned to ISO-standard device categories.

| Token | Width | Usage |
|-------|-------|-------|
| `breakpoints.mobile` | 320px | Small phones and narrow viewports |
| `breakpoints.tablet` | 768px | Tablets and medium viewports |
| `breakpoints.desktop` | 1024px | Desktop and laptop screens |
| `breakpoints.wide` | 1440px | Wide monitors and large displays |

**Media queries** (for JS usage):
```ts
mediaQueries.mobile   // '(min-width: 320px)'
mediaQueries.tablet   // '(min-width: 768px)'
mediaQueries.desktop  // '(min-width: 1024px)'
mediaQueries.wide     // '(min-width: 1440px)'
```

## Z-Index Scale

Layered z-index values for consistent stacking.

| Token | Value | Usage |
|-------|-------|-------|
| `zIndex.base` | 0 | Default stacking level |
| `zIndex.dropdown` | 100 | Dropdowns and select menus |
| `zIndex.sticky` | 200 | Sticky headers and navigation |
| `zIndex.overlay` | 300 | Overlay backgrounds |
| `zIndex.modal` | 400 | Modal dialogs |
| `zIndex.popover` | 500 | Popovers and tooltips |
| `zIndex.toast` | 600 | Toast notifications |
| `zIndex.tooltip` | 700 | Top-level tooltips |

## Transitions

| Token | Value | Usage |
|-------|-------|-------|
| `duration.fast` | 100ms | Micro-interactions (hover, focus) |
| `duration.normal` | 200ms | Standard transitions |
| `duration.slow` | 300ms | Complex animations |
| `duration.slower` | 500ms | Full-page transitions |

**Easing curves:**

| Name | Value | Usage |
|------|-------|-------|
| `easing.default` | `cubic-bezier(0.4, 0, 0.2, 1)` | Standard UBS easing |
| `easing.easeOut` | `cubic-bezier(0, 0, 0.2, 1)` | Enter / appear |
| `easing.easeIn` | `cubic-bezier(0.4, 0, 1, 1)` | Exit / disappear |
| `easing.impulse` | `cubic-bezier(0.22, 1, 0.36, 1)` | Spring-like impulse |

## Usage

Import tokens directly:

```tsx
import { spacing, breakpoints, zIndex, transitions } from '../index';

// Use in styled components or inline styles
const style = {
  padding: spacing.md,        // 32
  zIndex: zIndex.modal,       // 400
  transition: `all ${transitions.duration.normal} ${transitions.easing.default}`,
};
```

Or use CSS custom properties (injected by UBSThemeProvider):

```css
.myComponent {
  padding: var(--ubs-spacing-md);
  z-index: var(--ubs-z-modal);
  transition: all var(--ubs-duration-normal) var(--ubs-easing-default);
}
```
