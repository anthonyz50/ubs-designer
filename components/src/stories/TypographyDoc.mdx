# UBS Typography System

The UBS type hierarchy consists of 16 levels, all based on the Frutiger typeface (Arial fallback). This specimen sheet shows each level with its specification and sample text.

export const Specimen = ({ name, spec, weight, colour, sample, style }) => (
  <div style={{ marginBottom: 24, paddingBottom: 16, borderBottom: '1px solid #ECEBE4' }}>
    <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'baseline', marginBottom: 4 }}>
      <span style={{ fontFamily: 'Arial, sans-serif', fontSize: 12, fontWeight: 700, color: '#7A7870', textTransform: 'uppercase', letterSpacing: '0.05em' }}>
        {name}
      </span>
      <span style={{ fontFamily: 'monospace', fontSize: 11, color: '#8E8D83' }}>
        {spec} · {weight}{colour ? ` · ${colour}` : ''}
      </span>
    </div>
    <div style={{ fontFamily: "'Frutiger', Arial, sans-serif", ...style }}>
      {sample}
    </div>
  </div>
);

---

## Font Family

| Priority | Font | Usage |
|----------|------|-------|
| Primary | **Frutiger** | UBS corporate typeface (Monotype licence) |
| Fallback | **Arial** | Mandatory replacement when Frutiger unavailable |
| Mono | **Frutiger Mono** / SF Mono | Code, data tables |

## Font Weights

| Name | Weight | Usage |
|------|--------|-------|
| Light | 300 | General body text (Frutiger 45 Light) |
| Light Italic | 300i | Call-outs within body copy |
| Roman | 400 | Extra-small text for legibility (Frutiger 55 Roman) |
| Bold | 700 | Subheadlines, emphasis |
| Light Condensed | — | Diagrams only (Frutiger 47 Light CN) |

## Typography Rules

| Rule | Description |
|------|-------------|
| No red for numbers | UBS Red must **never** be used for numbers |
| No opacity | Never apply transparency to text |
| No small caps | Small caps are not permitted |
| No justification | Always left-aligned (RTL: right-aligned) |
| No right alignment | Except for RTL scripts |
| No text shadows | Drop shadows are prohibited |
| No centred blocks | Centred text blocks are not allowed |
| No mixed sizes | Never mix font sizes within one sentence |
| No text wrapping | Text must not wrap around objects |
| No red highlighting | Red highlighting in messages is no longer permitted |

## Web-Optimised Sizes

| Metric | Value |
|--------|-------|
| Minimum font size | 14px (10.5pt) |
| Recommended body | 16px (12pt) |
| Body line height | 22px (17pt) |
| Large text threshold | 25px (18pt) for WCAG contrast |
