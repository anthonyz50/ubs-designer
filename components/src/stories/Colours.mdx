## Colour Rules

- UBS Red **must never** be used for numbers
- Red highlighting in messages is **no longer permitted** for accessibility
- Colour alone must **never** convey meaning (WCAG 2.2 AA)
- Minimum contrast ratio: **4.5:1** for standard text, **3:1** for large text
- Chart segments with adjacent colour contrast below 3:1 must have a **2px gap**
