# Accessibility

The UBS Design System complies with **WCAG 2.2 Level AA**. Every component is built with accessibility as a first-class concern. This page documents the guidelines, contrast requirements, and rules that all UBS digital products must follow.

---

## Standard

All UBS digital and print communications must meet **WCAG 2.2 Level AA**.

---

## Contrast Requirements

### Minimum Ratios

| Content Type | Minimum Ratio | Applies To |
|-------------|---------------|------------|
| Standard text | **4.5:1** | Text smaller than 25px (or 18.7px bold) |
| Large text | **3:1** | Text 25px+ (or 18.7px+ bold) |
| Icons & graphics | **3:1** | Against background or adjacent colours |

## Accessibility Rules

### General

| Rule | Requirement |
|------|-------------|
| **Colour independence** | Colour alone must never convey meaning. Use icons, text, or patterns. |
| **Alternative text** | All non-decorative images must have meaningful alt text. |
| **Heading structure** | Documents must use a logical heading hierarchy (h1 → h2 → h3). |
| **Document title** | All documents must have a meaningful `<title>`. |
| **Language** | Documents must declare their language (`lang` attribute). |
| **Focus indicators** | All interactive elements must show visible focus (2px minimum). |
| **Touch targets** | Minimum 44px touch target size (WCAG 2.5.8). |

### Typography

| Rule | Requirement |
|------|-------------|
| **Minimum size** | 14px (10.5pt) absolute minimum across all text |
| **Recommended body** | 16px (12pt) for body text |
| **Line height** | 22px (17pt) for 16px body text |
| **Zoom support** | Content must work at 400% zoom without loss of functionality |
| **No text in images** | Avoid placing text within images. If necessary, 4.5:1 contrast minimum. |

### Data Visualisation

| Rule | Requirement |
|------|-------------|
| **Chart gaps** | 2px minimum gap between segments on screen when contrast < 3:1 |
| **Always 2D** | No 3D charts, ever |
| **Line types** | Use different line types for monochrome sequences |
| **Colour + shape** | Never rely on colour alone in charts |

## Component Compliance

Every component in this library includes:

- Semantic HTML elements with appropriate ARIA roles
- `aria-label` / `aria-labelledby` for non-text content
- `aria-live` regions for dynamic content (alerts, toasts)
- Focus management for interactive components
- Keyboard navigation support
- Sufficient colour contrast for all states
- `prefers-reduced-motion` support for animations

---

## Reporting Issues

If you find an accessibility issue in any component, please raise it as a **P1 (critical)** issue. Accessibility compliance is non-negotiable for UBS brand standards.
