## Accessibility Rules

### General

| Rule | Requirement |
|------|-------------|
| **Colour independence** | Colour alone must never convey meaning. Use icons, text, or patterns. |
| **Alternative text** | All non-decorative images must have meaningful alt text. |
| **Heading structure** | Documents must use a logical heading hierarchy (h1 → h2 → h3). |
| **Document title** | All documents must have a meaningful `<title>`. |
| **Language** | Documents must declare their language (`lang` attribute). |
| **Focus indicators** | All interactive elements must show visible focus (2px minimum). |
| **Touch targets** | Minimum 44px touch target size (WCAG 2.5.8). |

### Typography

| Rule | Requirement |
|------|-------------|
| **Minimum size** | 14px (10.5pt) absolute minimum across all text |
| **Recommended body** | 16px (12pt) for body text |
| **Line height** | 22px (17pt) for 16px body text |
| **Zoom support** | Content must work at 400% zoom without loss of functionality |
| **No text in images** | Avoid placing text within images. If necessary, 4.5:1 contrast minimum. |

### Data Visualisation

| Rule | Requirement |
|------|-------------|
| **Chart gaps** | 2px minimum gap between segments on screen when contrast < 3:1 |
| **Always 2D** | No 3D charts, ever |
| **Line types** | Use different line types for monochrome sequences |
| **Colour + shape** | Never rely on colour alone in charts |

Every component enforces UBS brand rules at the code level. UBS Red is never applied to numbers. Typography follows the 16-level UBS hierarchy. Charts are always 2D with correct colour sequences.

All components meet WCAG 2.2 Level AA requirements. Minimum contrast ratios of 4.5:1 for standard text and 3:1 for large text are enforced. Colour alone is never used to convey meaning.

Trading colours respect regional conventions. In EMEA and US markets, green indicates positive and red indicates negative values. In APAC markets, this is reversed.

## Typography Rules

| Rule | Description |
|------|-------------|
| No red for numbers | UBS Red must **never** be used for numbers |
| No opacity | Never apply transparency to text |
| No small caps | Small caps are not permitted |
| No justification | Always left-aligned (RTL: right-aligned) |
| No right alignment | Except for RTL scripts |
| No text shadows | Drop shadows are prohibited |
| No centred blocks | Centred text blocks are not allowed |
| No mixed sizes | Never mix font sizes within one sentence |
| No text wrapping | Text must not wrap around objects |
| No red highlighting | Red highlighting in messages is no longer permitted |
