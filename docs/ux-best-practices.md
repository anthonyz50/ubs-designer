# UBS UX Best Practices
Source: https://www.ubs.com/fx/en/web-publishing-guidelines/ux-best-practices.html

## Overview
UX best practices for optimising your web presence. Organised into 4 sections:
1. Fundamentals (usability, consistency, readability, accessibility, responsiveness)
2. Web Creation (purpose & audience, user journey, structure & hierarchy, content creation)
3. Practical Resources (checklists, recommended components, A/B testing insights)
4. Get Inspired (campaign pages, service/product offerings, articles)

## 1. Fundamentals

### 1.1 Usability
- Design for user goals to meet their needs and grow visitor engagement
- Keep interfaces simple and purposeful; focus only on what's relevant to the user
- Use familiar patterns and language to match user expectations and reduce friction
- Support flexibility and efficiency to empower users to work their own way faster
- Focus on clarity over decoration to guide attention to what really matters

**Principles:**
- **Simplify decisions:** Reduce the number of choices to help users act faster
- **Design for familiarity:** Use patterns and layouts users already know
- **Prioritise what matters:** Place key actions where users naturally focus, especially mobile
- **Guide with hierarchy:** Use size, spacing, and placement to lead the eye
- **Match real world:** Use language and visuals that reflect how users think and speak
- **Flexibility:** Allow users to personalise and adjust to their needs
- **Minimalist design:** Avoid information overload; keep layout clean and simple

### 1.2 Consistency and Coherence
- Maintain consistent design and layout for intuitive navigation
- Use familiar patterns and clear labels to simplify pages
- Standardise elements like buttons and links for predictable journeys
- Ensure image quality and style are consistent for trust and brand coherence
- Align sibling pages visually to support scanning

**Key rules:**
- Format elements the same way across all pages (links, buttons, contact info)
- Use clear, descriptive labels (avoid generic "click here")
- Use high-resolution images; choose consistent style across the journey
- Keep consistent spacing and alignment for clean, organised look

### 1.3 Readability
- Use clear, plain language to support fast reading
- Structure content with headings for easy navigation
- Keep line lengths 50-80 characters (inclusive of spaces)
- Break up long text for easy scanning
- Place key information first so users can act quickly
- Scannable writing improves usability by more than 120%
- Readers consume only 20-30% of content on average

**Text handling:**
- Use clear headings and subheadings
- Place important information up front
- Use bulleted lists for key information
- Enable jumping to sections
- Break up long text with proven methods

### 1.4 Accessibility
- Include captions and transcripts for all media
- Provide ALT text for images
- Avoid text in images; add exact text alternatives
- Add long descriptions to complex visuals
- Use structured tags in documents (PDFs, Office docs)
- Accessible video = title + captions + transcript
- Use proper heading hierarchy for screen readers

### 1.5 Responsiveness
- Design with mobile in mind; support key tasks across all screen sizes
- Prioritise CTA visibility on mobile for conversions
- Adapt layout and images per viewport
- Use high-resolution images for all devices
- Avoid images with text; always provide alt text
- Define the most useful image section per viewport using cropping

## 2. Web Creation

### 2.1 Purpose and Audience
- Define one clear business goal per page
- Identify target audience early for content relevance
- Link every action to business goal and user needs
- Use personas for deeper audience understanding
- Limit additional actions to keep users focused

**Business goals:** Increase traffic, conversions, engagement, or revenue
**Main action:** One per page, tied to business goal (contact form, download, subscribe, etc.)
**Additional actions:** Related content at the bottom; don't overload

**Audience types:** Affluent clients, small business owners, retirees, millennials, students
**Personas vs Target audience:** Target audience = broad group; Personas = detailed fictional representatives

### 2.2 User Journey
- Map the full journey across all channels and touchpoints
- Align user needs with business goals at every step
- Structure content like a funnel: broad → specific
- End each journey with a clear CTA
- Use data to test and optimise for shorter paths

**Good journey qualities:**
- Storytelling power: cohesive verbal and visual story
- Audience needs: align user needs with business goals
- Personalisation: tailor experience to preferences
- Responsive design: work well on all devices

**Optimisation:** Use analytics, heatmaps, navigation path tracking, A/B testing

### 2.3 Structure and Hierarchy
- Build clear information architecture
- Keep structure wide and shallow (max 3-4 levels)
- Use umbrella pages to guide from general to detailed
- Apply visual hierarchy to highlight key content
- Limit related content on deep pages (~10% of content page)

**Page types:**
- **Landing page:** Entry point from ads/emails
- **Topic site homepage:** Main page with site-wide settings
- **Article page:** Informative, engaging, easy to navigate

**Hierarchy tips:**
- Place important information first
- Use headings and subheadings for scanning
- Use white space to group related elements

### 2.4 Content Creation
- Craft strong keyline (headline) and infoline (subheadline)
- Tell structured, relevant stories reflecting user needs
- Use purposeful imagery supporting the message
- Design clear, benefit-driven CTAs
- Optimise for SEO

**Keyline best practices:**
- Ideal length: 55-65 characters
- Be clear, convincing, and charming
- Focus on benefits, not features
- Use personal language ("we", "our")

**CTA best practices:**
- Clear hierarchy: one primary button per page
- Prominent position: above the fold when possible
- Concise label: short and self-explanatory
- Clear wording: state the action explicitly (avoid "click here" or "read more")

**Button types:** Primary brand buttons, Secondary buttons, Action buttons

## 3. Practical Resources

### 3.1 Checklist: Starting a New Project
**Target audience and objectives:**
- Who is your target audience?
- What is the business goal of the page?
- What main action do you want the user to take?
- How is the user journey to/from this page?

**Content and structure:**
- Does your keyline & infoline match the page content?
- Are you focusing on the target audience needs and problems?
- Is your new layout similar in look and feel to peer pages?
- Is your content prepared to be accessible?

### 3.2 Checklist: Before Go Live
**Quality controls:**
- Do all links work?
- Are link labels meaningful?
- No spelling mistakes?
- Page content up-to-date and relevant?
- Visual hierarchy clear and consistent?

**Mobile view:**
- Content structured correctly on mobile?
- Most important CTA visible on mobile?
- Images displayed correctly on mobile?
- Tables displayed correctly on mobile?

**Readability:**
- Text width not more than 50-60% of page width?
- Long text optimised for scanning?
- Enough white space?

**Consistency:**
- Uniform visual language?
- Consistent formatting of links, lists, buttons?

**Accessibility:**
- Videos/audios have transcript?
- Non-decorative images have alt text?

### 3.3 Best Components
- **Jump to sections:** Allows users to quickly jump to different sections
- **Break up long copy:** Proven methods for managing large content
- **Prominent teasing:** Various ways to prominently tease new content
- **Timeline content:** Several ways to display content in a timeline
- **Attractive links:** Make important links stand out
- **Contact us:** Best practice suggestions
- **Video/audio:** How to manage white video cover images
