# Layout

> Bringing it all together for a distinctive identity

## Top Takeaways

1. The layout system defines the relationship between all elements. The situational needs and rules define how each element is applied.
2. The page format determines the proportions and sizes of the layout elements.
3. Whenever possible, we use **full-bleed images**. In other cases, we place the text on a white background.

---

## Layout Elements

- Format
- Logo Tab
- Text information
- Impulse
- Images
- Call-to-action element

---

## Grid

Types of grid layouts:
- Cover and back page
- Inside page
- Inside page with additional margin

## Margin

We keep a space of one height of the key symbol (k) between text and image as well as between text and margin.

### ISO Format Margins

| Format | Dimension (mm) | Margin (mm) |
|--------|----------------|-------------|
| A8 | 52 × 74 | 6.0 |
| A7 | 74 × 105 | 9.0 |
| A6 | 105 × 148 | 11.0 |
| A6/5 | 105 × 210 | 12.5 |
| A5 | 148 × 210 | 12.5 |
| A4 | 210 × 297 | 15.5 |
| A3 | 297 × 420 | 22.1 |
| A2 | 420 × 594 | 31.0 |
| A1 | 594 × 841 | 44.2 |
| A0 | 841 × 1189 | 62.1 |

## Do

Whenever possible, use full-bleed images. For special cases, gradually adjust the proportions between the image, the text and the white space so the image bleeds to the edge of two sides.

### Layout Options:
1. **Full bleed with Moving Frame** (recommended)
2. **Full bleed with Logo Tab** (for specific formats)
3. **Vertical two-thirds**
4. **Vertical half**
5. **Vertical one-thirds**
6. **Without image**

---

## Don't

- No margin on more than two sides
- No frameless white box
- No image from another corner
- No diagonal image crop
- No text and Impulse positioning on several areas
- No Moving Frame bleeds to the edge
