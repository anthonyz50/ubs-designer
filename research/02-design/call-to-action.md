# Call-to-Action

> Take the audience places with a button, text or URL

## Button
- For button text, use **bold font style of Frutiger**
- The stroke width of the arrow is based visually on the font weight

### Don't (Button)
- No other colours
- No multiline text

## Text
- For CTA text, align the arrow with the **x-height of the infoline**
- The arrow has an angle of **90 degrees**

### Don't (Text)
- No black
- No duplication
- No changing the angle

## URL
- On **Moving Frame:** align URL with half the height of key symbol (k) to the edge
- When combining image and text: use a key height to align distance of URL to image
- On **full white background:** align URL at margin with height of one key symbol (k)

### Don't (URL)
- No colour changes or misspelling
- No connecting with Impulse
- No multiple font styles
