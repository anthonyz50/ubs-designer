# UBS Icons — Introduction and Guidelines

> Source: UBS Frontify Portal, Standard Basics > Design Basics & Brand > Icon Introduction

## Principles

Icons must be:
- Distinct from each other
- Consistent in visual balance
- Self-explanatory
- Recognisable
- Easily visible under all possible user setups (screen resolutions and viewports)

UBS has a large number of pre-defined icons. Find the icon you need from within this set.

## Two Icon Types

### 1. Web Application Icons (24px and below)
- Used in applications for navigation and functional actions
- Consistent stroke weight (distinguishing feature from illustrative icons)
- Optimised for sizes up to 24px

### 2. Illustrative Icons (24px and above)
- Follow Brand Design Guidelines icon design
- Inspired by Frutiger Light font
- Preserve the light and bright look and feel
- Designed for 24px and upwards

**Critical:** Illustrative icons should be **avoided at all costs** within digital products as they lead to blurry appearance. For visual elements above 32px, use instructional or situational illustrations instead.

## Icon Appearance

Icons can be used as:
- **Indicators** — illustrating functions
- **Clickable buttons** — triggering actions

## Icon Labels

- Each icon is placed in the middle of a transparent square (safe area)
- Label placed directly below the square
- Maximum ~10 characters in a label name
- All UBS icons labelled in Frutiger font

## Icon Colours

- **Cod (#1C1C1C)** — on bright/light backgrounds
- **White (#FFFFFF)** — on dark backgrounds
- Same rules as text colour selection

### Icons with Specific Colour
Some icons have additional colours (e.g. brand icons, alerts, performance indicators). These are provided in the specific colour and are NOT provided as inverted versions.

## Icon Sizes

Icons are optimised (hinted) for specific display sizes. Optimised versions available for:
- **12px**
- **16px**
- **24px**

The correct icon for the displayed size is indicated by the suffix (e.g. `-12px`, `-16px`, `-24px`).

**Critical:** Always use the icon optimised for the size you're displaying. Using a 16px icon at 24px causes visible blurriness.

Legacy size 18px is available but will not be extended.
