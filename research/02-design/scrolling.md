# UBS Standard: Scrolling

> Source: UBS Frontify Portal, Standard Basics (Document 365)

## Where Content Can Be Scrolled
- On the page
- Within an area of the page (overlays, charts, tables/grids)
- Within a component (menus, dropdowns, accordions, expansion panels)

## Rules
- Always use default browser scrollbar style
- Scrollbars only visible on desktop if content doesn't fit container
- **Aim to only use vertical page scrollbar; avoid multiple scrollbars within areas**
- **Never use horizontal page scrollbar**

## Avoiding Scrollbars

### On Pages
- Design a responsive page
- Try a different layout

### Within Page Areas
- Use pagination or carousel to break content over multiple areas
- Try another component (inspector pane, overlay, tooltip) or display on new page

### Within Components
- Shorten text in the component
