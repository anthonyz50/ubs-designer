# Publications

> Make your mark with brochures, magazines and more

## Top Takeaways

1. Start with a format choice. Use a template or follow the Layout chapter for special formats.
2. Use examples for context and check accessibility for text on coloured backgrounds.
3. Use Special Elements for additional components.

---

## Basics

### Colour and Context
- Choose Gray base or add accents of Bordeaux or Bronze
- Consider customer journey or theme matching

### Design Principles
- **Highlight:** Full-space, striking images for emotional impact
- **Contrast:** Highlight important content and key points
- **Accent:** Organise information (e.g. Bordeaux III numbers on light background)
- **Interplay:** Incorporate all brand elements together
- **Variation:** Balanced overall impression within publication

## Fact Sheet

### Front Page (with Impulse)
- One column / One column with margin / Two columns

### Front Page (without Impulse)
- One column / One column with margin / Two columns

### Specifications
- **Logo:** Top left, aligned on column grid
- **Layout:** Align on column grid, various column widths
- **Message:** Fixed shoulder height, Frutiger Light
  - Keyline: **minimum 42 pt**
  - Infoline: **fixed 13.5 pt**
- **Typography:** Frutiger Light for lead/body, Frutiger Bold for hierarchy
- **Colours:** Red accent selectively, corporate + gray colours only
- **Disclaimer:** Place at end of content

### Back Page
- Logo bottom left, aligned on margins
- Sender information at end of content

## Greeting Card

- Consider regional, religious and cultural customs
- If logo on front, don't place logo inside
- If no logo on front, place logo inside

### Cover Options
- Full bleed / Full bleed with message
- Horizontal half with message
- Illustration with message / Embossing

---

## Direct Mail

- Use Layout and Publication guidelines
- Logo can be placed on inside page in multi-page direct mail
