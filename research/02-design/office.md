# Office Applications

> Giving everything in the office a touch of UBS

## Top Takeaways

1. Refer to Basic Elements chapter for logo, typography, Impulse, colours, etc.
2. Use Special Elements for additional requirements.
3. Use recommended tools and templates (UBS Templafy).

---

## Presentations

### Key Principles
- Use **UBS Templafy** (plug-in for PowerPoint) for consistent presentations
- **16:9 widescreen** for screen presentations
- Print presentation format only for printed pitch books
- Always open new Templafy presentation (don't overwrite existing)

### Classification
Cover page must show: Public, Internal, Confidential, or Strictly Confidential.

### Front Pages
- Key Symbol cover
- Image in portrait/landscape/extreme landscape format
- Marketing cover with full-bleed image
- Marketing cover with moving frame

### Inside Pages
- Agenda, Chapter page, various content layouts
- Tables, Charts, Graphics examples

### Don't (Presentations)
- No extra-long key lines
- No altered Key Symbol
- No busy picture backgrounds
- No red boxes or red in titles
- No 3D effects or shadows in charts
- No vertical lines or decorative shapes in tables

## Email

### Format
- **Standard HTML** (default)
- **Typography:** Aptos 11pt black, left aligned

### Standard Elements
- Header, Body, Signature, Disclaimer

### Signature
**Standard signature requires:**
- UBS logo (picture file)
- Legal company name
- Office/branch (if available)
- Department
- Street address/PO Box
- Postal code/Location
- Internal telephone number
- Direct telephone number
- URL

### Don't (Email)
- No keyboard symbols, emoticons, emojis, or tabs
- No coloured backgrounds
- No spinning logos, team pictures, or co-branding logos
- No name changes, logo size changes, or custom formatting

### Social Media Icons in Signatures
- 16px, Colour, PNG format
- Placed below the signature
- Hyperlink to official UBS platform
- Never add private profile links

### Out-of-Office
- Restrict information to external recipients (social engineering risk)
- No addresses unless authorised
- Provide only function names and public websites

## Correspondence (UBS Templafy)

Templates: Letter, Agenda, Report, Message

### Typography Sizes

| Element | Typeface | Size (pt) |
|---------|----------|-----------|
| Document title | Frutiger Light | 32 |
| Sender info (company name) | Frutiger Bold | 8-9 |
| Sender info (other) | Frutiger Light | 8-9 |
| Subject | Frutiger Bold | 10.5 |
| Content, date, references | Frutiger Light | 8-10.5 |
| Reference indication | Frutiger Bold | 8 |
| Endorsement/disclaimer | Frutiger Light | 5-6.5 |
| File name | Frutiger Light | 6-6.5 |
| Document information | Frutiger Light | 8-6.5 |

### Signature Requirements
- Two personal signatures standard for business correspondence
- Endorsement describes subsidiary-parent relationship
- Disclaimer is legally required (specific to business unit)

### Logo on Documents
- Colour for external use
- Black for internal use

## Envelopes and Labels

### Logo Placement Options
- Top left, bottom left, or bottom right on margin
- Same size for all formats
- If on front, not on back
- Observe local postal regulations

### Typography
- **Frutiger Bold:** Legal company name, mode of delivery, classification
- **Frutiger Light:** Department, address

### Discreet Envelopes
Many countries use no logo/sender info for client confidentiality. Check with legal.

### Numeral Maze
For extra security: print on inside of envelope so contents can't be seen from outside.
