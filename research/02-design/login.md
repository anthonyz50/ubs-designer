# UBS Standard: Login Page

> Source: UBS Frontify Portal, Standard Basics (Document 365)

## Overview
Login sets the scene and introduces user engagement. Most UBS online services require authentication.
Synonyms: Authentication, Registration

## Layout
Based on grid layout for UBS applications. Foundation uses tiles for modular approach.

## Areas/Tiles
- **Main tile** (REQUIRED)
- **Footer** (REQUIRED)
- **Additional tile** (optional) - extra information
- **Contextual tile** (optional) - contextual information

### Configurations
1. Main tile + Footer (simplest)
2. Main tile + Additional tile + Footer
3. Main tile + Contextual tile + Additional tile(s) + Footer

## Do's and Don'ts
- DON'T change tile positions (affects hierarchy and readability)
- DO use even gutters between tiles from layout grid
- DON'T position text outside tiles
- DON'T use dark background for tiles (always white for readability and brand consistency)
- DO use appropriate content length for balance
