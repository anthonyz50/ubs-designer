# UBS Standard Components: Avatar

> Source: UBS Frontify Portal, Standard Components (Document 17)

## Usage
Small visual element for differentiation among information types. Helps users understand data sources while complementing names, organisation names, or category types.

**Figma:** DDS-Library (node-id=1-100)  
**React (UWR):** Avatar

## Anatomy
1. Circle
2. Avatar content (Image, initials, or icon)
3. Alert (optional)

### Avatar Content Types
- Person's initials
- Person's photo
- Company logo
- Category icon

## Types
1. Visual representation of a company or person
2. Visual representation of a company or beneficiary
3. Visual representation of a category (account/payment type)

## Sizes
- **Basic** - standard size
- **Large** - larger variant

## Behaviour
Avatars are STATIC decorative elements. Only used alongside names.

### Rules
- Circle filled with Gallery (grey) background OR image. NO alternative colours.
- Initials and icons inside: Cod Gray ONLY
- Company logos must NOT be cut or squashed
- If no company logo available, use first letter of company name
- Initials: first letters of first and last names, correct order
- Each type can have an Alert badge
- DON'T use red or other colours inside an Avatar
- DON'T create custom logos; use first letter fallback
