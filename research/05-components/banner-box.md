# UBS Standard Component: Banner Box

> Source: UBS Frontify Portal, Standard Components (Document 17)
> Figma: https://www.figma.com/file/WcC0f87A9v8ZEp6EaU8k4T/DDS-Library?type=design&node-id=1430-16185&mode=design
> React (UWR): BannerBox

## Usage
Dynamic element for displaying promotional information and important service notifications. Does NOT require user action; user can proceed without confirmation or denial.

## Anatomy
1. Icon or Illustration
2. Headline
3. Description (optional)
4. Close Button (optional)
5. Button or Link set

## Types

### Basic Banner Box
Uses icon in grey circle. Icons from Web app icon library.

### Illustration Banner Box
More engaging and personal. Use ONLY illustrations from approved Illustrations library.

### Ghost Banner Box
Placed ONLY on top of Bottombar Overlay. Available in Ghost Basic and Ghost Illustration variants.

### Sizes
- Basic (standard)
- Small
Both valid for Banner Box and Ghost Banner Box.

## Behaviour
- Triggered by user actions or to provide contextual information
- Can be dismissed by user
- Does NOT require action
- Ghost variant appears only at bottom of page (on Bottombar Overlay)

## Do's and Don'ts
- DO: Use only 1 line for Headline and 2 lines for Description
- DO: Use defined icons
- DO: Use approved square illustrations from library
- DON'T: Use more than 3 lines for Headline and Description combined
- DON'T: Use undefined icons or avatars
- DON'T: Use horizontal illustrations
- DON'T: Design illustrations yourself
