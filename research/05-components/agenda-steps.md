# UBS Standard Component: Agenda Steps

> Source: UBS Frontify Portal, Standard Components (Document 17)
> Figma: https://www.figma.com/file/WcC0f87A9v8ZEp6EaU8k4T/DDS-Library?type=design&node-id=1433-21462&mode=design
> React (UWR): AgendaSteps

## Usage
Visual representation of process steps (e.g. onboarding). Shows what has been done and what will need to be done.
Synonyms: Agenda, Steps, Stepper, Progress, Actions

## Anatomy
1. Progress indicator
2. Title
3. Subline

## Types
1. Title only
2. Title with subline text

### Colour Variations
- **Cod** (dark) - default colour
- **Red** - for brand-related content

### Past Step Icon Variations
- Default icon
- Custom icon

## Behaviour
- Use ONLY as part of a long process
- Give option to save current progress whenever possible
- Every step is mandatory
- ALWAYS combine with Tile component

## Do's and Don'ts
- DO: Use only one type of step at a time
- DON'T: Combine different types of steps
