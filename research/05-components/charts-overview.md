# UBS Standard Components: Charts Overview

> Source: UBS Frontify Portal, Standard Components (Document 17)

## Overview
Charts are visual representations of data for quick readability. Five major chart types plus chart-related elements.

## Chart Elements
1. **Canvas** - the chart container
2. **Crosshair** - hover indicator
3. **Legend** - data series labels
4. **Data Markers** - individual data points
5. **Colours** - chart colour palette (use UBS Charts colour palette in given sequence)

## Chart Anatomy
1. Legend
2. Chart series
3. Data Markers
4. Axis
5. Regular guideline
6. Chart title
7. Chart description
8. Plot area
9. Label
10. Tick mark

## Chart Types

### Line Charts
- Visualise trends and changes over time or continuous variables
- Ideal for quantitative data with clear progression (stock prices, revenue growth, GDP changes)

### Bar/Column Charts
- Compare discrete categories or groups
- Suitable for categorical data (sales by region, expenses by category)

### Donut Charts
- Showcase parts of a whole or proportions
- Useful for percentages/distributions (market share, budget allocation, portfolio asset classes)

### Area Charts
- Visualise cumulative data or continuous progression
- Suitable for quantitative data over time (total revenue, investment portfolio, stock performance)

### Mixed Charts
- Show multiple chart types within single plot
- Useful for complex data relationships (comparing bar and line simultaneously)

### Sparkline
- Minimal inline chart for trends within text or table cells

### Maps
- Geographic data visualisation

## Qualities/Rules
- Use UBS Charts colour palette with colours in given sequence
- You can start first colour from any point in the sequence
- Charts can have more or fewer elements depending on needs
- Horizontal axis (x) can be omitted if content remains comprehensible

## Context Elements
- **Name** (plot name) - succinct description of what data refers to
- **Subname** (inset) - additional information about the graph if needed
- **Value** - sum of values in the chart
