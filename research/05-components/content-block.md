# UBS Standard Components: Content Block

> Source: UBS Frontify Portal, Standard Components (Document 17)

## Usage
Base component for other elements (Tiles, Panels, Tabs, etc.). Style depends on surface below.

**Figma:** DDS-Library (node-id=290-6524)  
**React (UWR):** ContentBlock  
**Related:** Tiles, Panels, Filter, Tabs

## Anatomy
1. Content wrapper (shadow or boxed)
2. Placeholder for content

## Types
- **Shadow** - use on Concrete (grey) background
- **Boxed** - use on White background

### Rules
- Shadow type ONLY on Concrete background
- Boxed type ONLY on White background
- Never mix (no shadow on white, no boxed on concrete)
